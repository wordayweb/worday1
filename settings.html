وِرْدِي كتطبيق حقيقي

ثبّت وِرْدِي على جهازك ليعمل بدون إنترنت ويفتح بسرعة البرق مثل أي تطبيق آخر.

أو اتبع الخطوات أدناه حسب جهازك

📴 بدون إنترنت الأذكار والقرآن متاحة دائمًا
⚡ فتح فوري لا انتظار، لا تحميل
🏠 أيقونة على الشاشة مثل أي تطبيق آخر
💾 صغير الحجم لا يأخذ مساحة
🤖 أندرويد (Chrome) ›
  1. افتح موقع وِرْدِي في متصفح Chrome
  2. سيظهر إشعار "📲 ثبّت التطبيق" في الأسفل
  3. اضغط عليه → سيُثبَّت التطبيق فورًا
  4. إذا لم يظهر، اضغط قائمة Chrome (⋮) → "تثبيت التطبيق"
🍎 آيفون / آيباد (Safari) ›
  1. افتح موقع وِرْدِي في متصفح Safari
  2. اضغط زر المشاركة □↗ في الأسفل
  3. انزل واختر "إضافة إلى الشاشة الرئيسية"
  4. اضغط "إضافة" في الأعلى
  5. ستظهر أيقونة وِرْدِي على شاشتك ✨
💻 ويندوز (Edge / Chrome) ›
  1. افتح موقع وِرْدِي في Edge أو Chrome
  2. ابحث عن أيقونة ⊕ أو 📥 في شريط العنوان
  3. اضغطها → "تثبيت وِرْدِي"
  4. أو من قائمة المتصفح: تطبيقات → تثبيت هذا الموقع كتطبيق
🍏 ماك (Safari / Chrome) ›
  1. Safari: من قائمة File → Add to Dock
  2. Chrome: من قائمة ⋮ → Cast, save, and share → Install page as app
